# charmes-nouveau

Static website repository for Charmes Nouveau.

- Target site: https://charmes-nouveau.chu.jp/
- Local workspace: `/Users/atsufumikashima/Python/24_charmes-nouveau`
- Current preview entry: `index.html`

## Repository layout

- `config/`: shared configuration
- `data/`: generated outputs, artifacts, and runtime logs
- `docs/`: requirements and documentation
- `src/`: implementation code
- `old/`: archived legacy assets

See `docs/project-brief.md` for the initial project note.
