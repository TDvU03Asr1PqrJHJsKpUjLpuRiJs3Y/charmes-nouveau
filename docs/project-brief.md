# Project brief

## Goal

Create a new website repository for Charmes Nouveau.

## Target URL

https://charmes-nouveau.chu.jp/

## Initial repository policy

The initial commit keeps the repository minimal and follows the repository layout policy:

- `config/` for shared configuration
- `data/` for generated outputs, artifacts, and runtime logs
- `docs/` for documentation
- `src/` for implementation code
- `old/` for archived legacy assets

Website implementation files will be added in a later step.
